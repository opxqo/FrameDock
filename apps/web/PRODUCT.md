# Product

## Platform

web

## Users

独立创作者和小工作室。自己部署 FrameDock，在桌面大屏上长时间搭建创作流程：文案 → 分镜图 → 视频，反复尝试不同模型。关心两件事：每次生成花多少钱，产出有多快。

## Product Purpose

FrameDock（帧坞）是自部署的无限画布 + 节点式工作流工具，用于 AI 图片和视频生成。创作者在画布上摆放文本、图片、视频节点，用连线表达数据依赖，可以单节点重跑，也可以整条链运行。
成功的标准：从一句想法到一条可用的视频，路径短、反馈快、花费可预期。失败时能立即看到是哪一步出了问题，改完只重跑受影响的部分。

## Positioning

- **连线即数据依赖**：画布上的连线就是工作流。支持“运行到此处 / 运行下游”，某个节点失败时阻断下游。updream 的连线只表示引用关系；ComfyUI 是面向工程师的技术节点。
- **自部署**：服务、数据库、素材都在用户自己的机器上。
- **一个 Key 用全部模型**：通过 AutoDL.Art，一个 API Key 就能使用对话、图片、视频模型，每个模型都显示价格提示。

## Operating Context

- 桌面浏览器，大屏，单次使用时间长；主要页面是画布编辑器。
- 典型链路：文本节点（剧本 / 提示词）→ 图片生成节点（分镜、角色）→ 视频生成节点（首尾帧、参考图）。
- 视频生成一次要几分钟到十几分钟，期间用户会继续编辑画布的其他部分。
- 模型来自 AutoDL：MiniMax 海螺、可灵、Seedance、万相、Gemini、Qwen-Image 等。开发环境下另有一个“本地模拟”渠道，用来做不花钱的测试。

## Capabilities and Constraints

- 前端：React 19 + Vite + antd 6 + Tailwind v4 + Zustand，基于 infinite-canvas（MIT）复制而来。后端：Fastify + SQLite，负责共享存储、代理和模拟接口。
- 已有功能：
  - 节点：文本、图片、视频、音频、分组；
  - 生成：单节点生成、运行到此处 / 运行下游、停止，视频任务刷新后可以恢复；
  - 编辑：撤销 / 重做、吸附对齐、裁剪 / 蒙版 / 分割 / 放大；
  - 其他页面：素材库、提示词库，以及独立的生图 / 视频工作台；
  - 模型渠道配置：AutoDL 专区，以及自定义渠道；
  - 次要功能：WebDAV 同步、本地代理、插件、本地 Agent 面板。
- 单用户，不做登录和协作。
- 界面以中文为主，英文界面必须继续可用（`i18n/locales/zh-CN.ts`、`en-US.ts`）。
- 未定：服务端执行引擎和输入哈希缓存尚未实现（见 `docs/design.md` 第 6 节）。

## Product Principles

1. 素材是主角：图片和视频结果占据视觉重心，界面本身退到后面。
2. 状态一眼可见：每个节点是待运行、排队、运行中、成功、失败还是已过期，不用点开就能知道。
3. 花费透明：选模型时就能看到价格，不要等到出账单才知道。
4. 少打断：参数设置尽量就地完成，键盘能完成高频操作，运行长任务时不阻塞继续编辑。
5. 失败可恢复：错误信息要说明哪一步出了什么问题、怎么修，修完只重跑受影响的部分。
