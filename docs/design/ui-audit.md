## 第二次改版：updream 设计语言（2026-10-17）

用户看过画布交互原型后，确认改用 updream 设计语言，并要求换掉图标。现行规范见 `apps/web/DESIGN.md`，调研原文见 `docs/research/updream-design-language.md`。

| 项 | 处理 |
|---|---|
| 图标 | 全站从 lucide 换成 Solar 线性图标：通过 `unplugin-icons` 在构建时编译，统一入口是 `src/components/icons.tsx`；“抓手”图标为自绘 |
| 配色 | 改为近黑、纯中性灰阶，白色作为唯一强调色；状态色只保留绿 / 红 / 琥珀 |
| 材质 | 浮层统一使用 `.glass`（75% 不透明 + 20px 模糊），antd 的下拉、气泡、选择框也一并覆盖 |
| 画布外围工具 | 顶栏改为左右两个浮动胶囊；添加工具放在左侧 52px 竖条；视图控制合并为底部居中的 dock；节目条改为顶部居中胶囊 |
| 画布内容 | 点阵按倍频调整间距、低缩放时淡出；连线采用 updream 的控制柄、线宽、命中区，并加流动亮段；节点为 8px 圆角，选中态是白描边加外圈，端口回弹弹出，生成中显示扫光，失败显示覆盖层 |
| C5 | ✅ 参数层改为玻璃材质、加宽，下方放不下时翻到节点上方 |
| 缺陷 | 修复 antd `reset.css` 没有放进 CSS 层、导致 `<button>` 上的 Tailwind 文字颜色全部失效的问题（现在放在 `base` 层） |

未做：停用引用的虚线连线（数据模型里还没有“停用引用”字段）。
