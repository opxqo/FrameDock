# T019 — 美术资产节点（第一个官方预制节点）

状态：验收通过（Claude 实现并验收），样板版
日期：2026-10-18

## 目的

把提炼好的提示词封装成开箱即用的组件节点。第一个是“美术资产”：为视频产出人物、场景、服装、道具的参考素材。分类思路参考 MOKE 提示词库的“美术资产”栏目，提示词由 FrameDock 自己编写。

## 做法

### 模板
`lib/art-assets/templates.ts`，纯数据加组装函数。共 8 个模板，四类各 2 个：

| 类别 | 模板 | 输入要求 |
|---|---|---|
| 人物 | 角色三视图 | 图或描述 |
| 人物 | 表情九宫格 | 图或描述 |
| 场景 | 空景提取 | 必须有图 |
| 场景 | 场景四机位 | 图或描述 |
| 服装 | 服装拆解 | 必须有图 |
| 服装 | 服装三视图 | 图或描述 |
| 道具 | 道具多视图 | 图或描述 |
| 道具 | 道具提取 | 必须有图 |

`composeArtAssetPrompt` 按以下顺序拼出最终提示词：
1. 模板正文；
2. 连了参考图时，加一致性要求；
3. 【补充描述】：面板里的文字，加上游文本节点的内容；
4. 棚拍背景与光线（场景类不加）；
5. 通用禁止项。

没有任何输入、或模板要求图但没有图时，返回错误码，不发请求。

### 节点
`components/canvas/nodes/art-asset-node.tsx`：
- 类型为 `framedock:art-asset`，出现在“新建节点”菜单和工具栏“扩展”里。
- 卡片上切换类别和模板。选模板时把推荐比例写进节点的 `size`。
- 生成中和出错时，卡片保持显示，在底部用一行文字提示状态。
- 下方复用内置的图片生成面板：输入框改作可选的“补充描述”，空着也能生成。

### 宿主新增的可选钩子
`CanvasBuiltinPanelConfig` 新增：
- `allowEmptyPrompt`
- `promptPlaceholder`
- `composePrompt`
- `resultTitle`

用到这些钩子的地方：
- `handleGenerateNode`（`pages/canvas/project.tsx`）：
  - 拿到参考图后组装提示词；
  - 缺少输入时只弹警告，节点状态不变；
  - 结果节点放在右侧并连线，标题为“类别 · 模板”；
  - 源节点不再像普通节点那样被转换成文本节点。
- `canvas-node.tsx`：预制节点在 loading 和 error 状态下照常显示自己的卡片。
- `withPreferredYfaiRatio`（`lib/yfai-catalog.ts`）：YFAI 模型的比例参数在用户没选、仍为“自动”时，填入模板的推荐比例，前提是该模型支持这个比例。

## 验证

- `bun test` 共 92 项通过。新增 5 项：
  - 模板完整性与中英文案；
  - 只有描述时的组装；

  - YFAI 比例填充规则。
- `pnpm typecheck` 通过。

### 浏览器检查
在测试画布上进行，已删除；生成请求在页面里被拦截，没有产生费用。
- 新建菜单里有“美术资产”。
- 切换模板后，推荐比例写入节点。
- 什么都不填就生成：弹出警告，没有发出请求。
- 填写描述后生成：
  - 拦截到的 `/api/jobs` 请求里，提示词是“模板 + 【补充描述】 + 规则”；
  - `aspect_ratio` 为 16:9；
  - 结果节点在右侧、已连线，标题“人物 · 角色三视图”。
- YFAI dry-run（¥0）接受了这个请求，发往 MJ 的正文末尾带 `--ar 16:9`。
