# T006 — YFAI 单 Key 接入

状态：已完成，待验收

## 用户任务

像 AutoDL.Art 一样接入 `https://yf.token6688.com`，用户填写一个 Key 即可使用该服务商的模型。

## 范围

- 设置中的独立 YFAI 专区：固定地址、Key、免费验证与同步、分类搜索、模型开关、设为默认。
- 官方模型目录和参数规则；对话、图片、视频、音频生成适配。
- 素材上传、异步任务查询、视频任务刷新恢复、结果回填。
- 独立工具调用入口用于转写、声音设计、声音克隆以及其它模型操作。
- 账户估价、中英文文案、适配测试和浏览器检查。

不修改设计文档，不修改参考项目，不提交 Git。

## MJ 参考图报错修复

- 用户症状：MJ 生成报 `operation=edit requires attachments[0] (source image)`。
- 用实际 `requestEdit` → 上传 → runtime 提交路径构造最小回归：一张合成参考图；初次测试 0 pass / 1 fail，出现同一错误文本。
- 原因：原适配器错误地按“有参考图”推断 edit，并漏传顶层 attachments；与 MJ 仅支持垫图生成 / Blend 的模式不符。
- 修复：按模型有效模式决定 operation；真正 image-edit 发送 edit，MJ 参考 / Blend 发送 generate；图片源在顶层 attachments 传入，保留模型参数中的参考图字段。
- 新增 5 项回归：MJ 单图、MJ Blend、真正图编辑、空参考列表、单 URL 超分输入；新测试先复现失败、修复后转绿。
