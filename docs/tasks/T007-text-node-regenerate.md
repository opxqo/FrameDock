# T007 — 文本与图片卡片原位重新生成

状态：已完成，待验收

## 用户任务

选中已有文本或图片卡片，修改提示词后再次生成时，更新当前卡片，而不是额外创建一个新卡片。

## 范围

- 已有内容的文本和图片节点显示明确的“重新生成”操作。
- 该操作明确覆盖当前节点，不受默认“新建分支”设置影响；图片重生成仍将当前图作为参考。
- 成功后更新原节点；失败或取消时保留已有输出。

## 不要做的事

- 不更改工作流其他节点、连线、提示词或模型配置。
- 不改变空白文本节点和其他媒体节点的默认生成行为。
- 不执行 git 提交。

## 验收标准

- [x] 已有文本或图片内容时，按钮明确显示“重新生成”。
- [x] 点击后复用当前节点，不增加节点或连线；图片沿用当前图作为参考输入。
- [x] 重新生成失败或取消时，旧的文本 / 图片输出仍保留。
- [x] 中英文界面都有对应按钮文案。
