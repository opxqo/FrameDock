# T014 — 同步型任务：图片、音频、文本走 job（任务系统 P3）

状态：待执行
前置：T012、T013 验收
方案：[backend-jobs-plan.md](../design/backend-jobs-plan.md) 阶段 P3

## 范围

1. 服务端新增 `image`、`audio`、`text` 通用适配器：浏览器提交已构造好的上游请求规格（方法、地址、头、体，素材引用 kv 键），服务端发起长请求并等待，响应落 blob，浏览器用现有解析代码处理。
2. 请求超时沿用 20 分钟；服务重启时这类任务进入 `unknown`（不保证恢复，只保证关闭页面后继续）。
3. 前端在图片、音频、文本的发起点接入 job，沿用 T013 的对账与开关。
4. 取消：浏览器路径 abort；job 路径调用取消接口。

## 不要做的事

- 不重写 `image.ts` 的请求构造和解析。
- 不对 `unknown` 自动重试。

## 验收标准

- [ ] 图片生成中关闭页面，重开后结果出现在节点上。
- [ ] 取消后不再有结果写入节点。
- [ ] 关闭 `useServerJobs` 后行为不变。
- [ ] 相关 typecheck 与测试通过。
