# T017 — 一键调色对齐

状态：验收通过（Claude 实现并验收）
日期：2026-10-18

## 目的

图生图时同一场景多张图亮度、色温、对比度不一致。以一张母版为准，把其他图的整体颜色统计对齐到它。本地计算，不调用模型、不花钱；原图保留，结果作为新节点。只统一颜色和明暗，不改光源方向和阴影位置。

## 做法

- 算法 `lib/color-match.ts`：Reinhard 颜色迁移，转 CIE Lab，按通道对齐均值和标准差；强度 0–100%（默认 80%）；范围“颜色和亮度”或“只对齐色调”（不动 L）；统计时忽略近黑/近白与透明像素；保留透明度；无可用像素时原样返回。
- 图片读写 `lib/canvas/canvas-image-data.ts`：`readImagePixels`、`pixelsToDataUrl`、`colorMatchDataUrl`（母版统计用长边 512px 的缩略图，结果按原尺寸输出）。
- 入口：图片快捷工具“调色对齐”（`colorMatch`，默认显示）。已保存过快捷工具设置的用户会自动补上这一项一次（配置里记录已见过的工具），之后由用户自行增删。
- 对话框 `components/canvas/canvas-node-color-match-dialog.tsx`：选母版（默认取以“参考 / 首帧”连进来的图）、强度、范围、原图 / 对齐后实时预览；画布上同时选中的其他图片可一并对齐。
- 结果：每张目标图在右侧生成新节点“{原标题} · 调色”，从原图连线过去，`metadata.colorMatch` 记录母版与参数，沿用原 prompt。

## 验证

- `bun test` 81 项通过（新增 7 项：Lab 往返、偏暖偏暗图对齐到中性母版均值误差 < 1、强度 0 原样 / 50% 居中、只对齐色调时亮度不变、纯黑纯白不影响统计、透明度保留、空白图原样）；`pnpm typecheck` 通过。
- 浏览器（测试画布，已删除）：暖色母版 + 两张冷色图，对 SHOT 2 打开“调色对齐”，选母版后预览从冷色变为暖色；确认后右侧出现“冷2 · 调色”并连线，原图不变。
- 未在浏览器里单独点验：批量对齐（多选后勾选其他图）、默认母版（参考连线）、“只对齐色调”的界面切换——逻辑由单元测试覆盖。
