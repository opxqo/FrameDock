# T020 — 人物定稿 / 人物派生 两级节点（模板来自 MOKE）

状态：验收通过（Claude 实现并验收）
日期：2026-10-18

## 目的

T019 的单个“美术资产”节点每次都从文字重新生成，同一个角色在三视图和表情图里会长得不一样。现在按“先定稿、再派生”拆成两级节点：派生节点必须连着定稿图，所有派生都以那张图为准。模板和提示词按用户要求直接沿用 MOKE AIGC 提示词库的“美术资产”栏目，规则已写入 AGENTS.md。

## 做法

### 模板
`lib/art-assets/character-templates.ts`：MOKE 原文，只修正 T-Pose 条目里明显的机翻错字。

| 层级 | 模板 |
|---|---|
| 一级 · 定稿 | 角色三视图（可以只用描述）、三视图与局部特写、四视展示图、角色全身补全 |
| 二级 · 派生（必须有图） | 一键表情图、标准 T-Pose、标准 A-Pose、角色设定拆解、角色 Q 版化、Q 版转正常、同风格创意衍生 |

- MOKE 的“可选参数”做成了模板选项，在卡片上点选，写入提示词里的 `{{id}}`：
  - 表情图：出图范围；
  - Q 版化：Q 版比例；
  - Q 版转正常：目标体型。
- `[主体]` 的处理：
  - 有描述时替换成描述；
  - 没有描述时去掉“或 [主体]”，原文变成“以参考角色为主体”；
  - 模板里没有 `[主体]` 时，描述作为【补充描述】追加在末尾。
- MOKE 模板原样发送，不再加 FrameDock 自己的通用规则。

### 节点
`components/canvas/nodes/art-asset-node.tsx`：同一套实现，按配置生成节点。
- **人物定稿**（`framedock:character-master`）和**人物派生**（`framedock:character-derive`）在新建菜单和工具栏“扩展”里归在“美术资产”分组下。分组靠 `CanvasNodeDefinition.group` 加 `groupDefinitions`。
- 派生节点的卡片：
  - 显示连进来的定稿缩略图，第一张为主参考；
  - 没连图时显示提示；直接点生成会被拦下，弹出“派生需要先连一张人物定稿图”，不发请求。
- **一键派生**：定稿节点生成的图片会记下 `metadata.artAssetFrom`，这张图的工具栏多出“派生”按钮。点了就在右边新建一个人物派生节点并连好线。规则在 `lib/art-assets/node-types.ts`。
- T019 的合并节点不再出现在菜单里，已有画布照常能用。

## 追加（同日）：定稿节点共用自己产出的母版

**问题**：人物定稿生成三视图后，在同一个节点切到“四视展示图”等需要参考图的模板，会提示需要参考图，只能再建一个定稿节点、手动把结果连进去。

**做法**：
- 定稿节点产出的图（从它连出、带 `artAssetFrom` 标记的图片）就是这个节点的资产，默认第一张为母版（`lib/art-assets/node-types.ts` 的 `artAssetMaster`）。
- 之后再生成，母版自动作为第一张参考图一起发送（`useBuiltinPanel.ownReferences`），排在连进来的图前面。
- 卡片顶部显示母版缩略图：
  - 点缩略图可以换一张当母版；
  - “不用母版”可以关掉，改成重新设计。
- 同一个节点的新结果依次排在已有结果下方，不再叠在同一个位置。

**验证**：
- 单元测试共 96 项通过，新增一项覆盖：母版取第一张、手动指定、指定的图已删除时回退、关闭共用、没有产出时为空。
- 浏览器：在你的画布上，左边那个人物定稿节点切到“四视展示图”后直接生成（请求被拦截），不再报错。拦截到的请求里：
  - 三视图结果作为参考图发送，模式为 image-edit；
  - 比例 1:1；
  - 正文是 MOKE 的四视展示图原文。
- 测试结束后，已删掉产生的失败节点，模板也切回了原来的选择。
